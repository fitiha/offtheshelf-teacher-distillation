# Notebooks Overview

All four notebooks were executed in Kaggle/Google Colab (Python 3.12.13, single NVIDIA T4 GPU) using Hugging Face `transformers`, `datasets`, `accelerate`, and PyTorch. Note that notebooks `02` and `04` have swapped filenames relative to the experiments they contain (see below).

## `01_main_sweep_and_alpha.ipynb`
This notebook runs the primary TinyStories experiments with the frozen off-the-shelf `gpt2` teacher (`124M` parameters). It loads `roneneldan/TinyStories` (20,000 training and 2,000 validation examples, max sequence length 128), defines the five GPT-2 student configurations (`Tiny` 7.24M, `Zoom` 8.26M, `XSmall` 9.30M, `Small` 12.34M, `Medium` 19.22M), and trains baseline and distilled (`T = 2.0`) models for 1 epoch with batch size 16. Earlier cells (0–87) reflect initial runs prior to correcting the `Trainer.evaluate()` metric bug; cells 88–91 implement `train_and_pure_eval` (re-evaluating with a plain `Trainer`) for the $\alpha \in \{0.25, 0.5, 0.75, 1.0\}$ sweep and the two-seed (`42`, `999`) $\alpha = 0.5$ size sweep, and cells 92–93 run the padding-mask control (`DistillationTrainerMasked`) on `Tiny`. Outputs are printed validation cross-entropy losses (`eval_loss`) and two exploratory plots (`distillation_gap_vs_size.png`, `distillation_gap_full.png`). Per-condition wall-clock times from Table 2 of the paper are ~1.4–2.9 min (baseline) and ~5.5–6.8 min (distilled); total notebook runtime is not logged. Reproduces **Sections 5, 6.1, 6.2, and 8** (**Tables 1, 3, 4; Figures 1, 2; padding-mask check**).

## `02_gptneo_teacher_generalization.ipynb`
*(Filename note: despite its filename, this notebook runs the **WikiText-2 domain-swap** experiment with GPT-Neo-125M, not the TinyStories teacher-generalization sweep.)* It loads `wikitext` (`wikitext-2-raw-v1`), filters out lines with `len(x["text"].strip()) <= 20`, selects up to 20,000 training and 2,000 validation examples, and loads `EleutherAI/gpt-neo-125m` (`125.2M` parameters) as the frozen teacher. It trains and evaluates baseline and distilled (`alpha = 0.5`, `T = 2.0`, `seed = 42`) models for `Tiny` and `Medium` using plain `Trainer` evaluation, printing `wiki_neo_results` (`Tiny`: baseline `7.554`, distilled `7.699`, gap `-0.145`; `Medium`: baseline `6.882`, distilled `6.992`, gap `-0.110`) alongside a summary comparison table. Per-condition runtimes follow Table 2 (~1.4–2.9 min baseline, ~5.5–6.8 min distilled on T4); total notebook runtime is not logged. Reproduces the GPT-Neo half of **Section 6.4** (**Table 6, Figure 3**).

## `03_wikitext_domain_swap_gpt2.ipynb`
This notebook runs the WikiText-2 domain-swap experiment with the frozen `gpt2` teacher (`124M` parameters). Using the same `wikitext` (`wikitext-2-raw-v1`) preprocessing (`len(x["text"].strip()) > 20`, up to 20,000 training and 2,000 validation examples), it trains and evaluates baseline and distilled (`alpha = 0.5`, `T = 2.0`, `seed = 42`) models at `Tiny` and `Medium` using plain `Trainer` evaluation. It prints `wiki_results` (`Tiny`: baseline `7.554`, distilled `7.760`, gap `-0.206`; `Medium`: baseline `6.882`, distilled `6.965`, gap `-0.083`). Per-condition runtimes follow Table 2 (~1.4–2.9 min baseline, ~5.5–6.8 min distilled on T4); total notebook runtime is not logged. Reproduces the GPT-2 half of **Section 6.4** (**Table 6, Figure 3**).

## `04_wikitext_domain_swap_gptneo.ipynb`
*(Filename note: despite its filename, this notebook runs the **TinyStories teacher-generalization** sweep with GPT-Neo-125M, not the WikiText-2 domain swap.)* It loads `roneneldan/TinyStories` (20,000 training and 2,000 validation examples) and `EleutherAI/gpt-neo-125m` (`125.2M` parameters) as the frozen teacher, then trains and evaluates distilled models (`alpha = 0.5`, `T = 2.0`, `seed = 42`) across all five student sizes (`Tiny`, `Zoom`, `XSmall`, `Small`, `Medium`) using plain `Trainer` evaluation. It prints `neo_results` (`Tiny`: `6.226`, `Zoom`: `5.939`, `XSmall`: `5.763`, `Small`: `5.338`, `Medium`: `4.700`) and a comparison table against the GPT-2 baseline/distilled numbers. Per-condition runtimes follow Table 2 (~5.5–6.8 min per distilled run on T4); total notebook runtime is not logged. Reproduces **Section 6.3** (**Table 5**).
